# product-landing-page
This is my product landing page for Responsive Web Design. I built this project using basic HTML and CSS to practice page layout and styling.

What I Used:

HTML: <header> , <main>, <section>, and <footer> to organize the page, also a simple email signup form.

CSS: Flexbox to line up the navigation links and put the product cards side-by-side.
Colors & Buttons: Styled the main signup button in orange so it stands out, and matched the store buttons to the dark blue header.

How to Open It
1. Download the files into the same folder.
2. Double-click index.html to view it in your web browser.
